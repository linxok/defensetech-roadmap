# Домашнє завдання 16: Портфоліо-проєкти

Три завдання на тиждень. Кожне закривається артефактом і перевіркою,
а не «зробив» на віру.

## README-аудит

Перепишіть README за схемою проблема → метрики.

Критерій приймання: README проходить чекліст і містить числа.

## Демо

Запишіть відео 2 хвилини: запуск і живий результат.

Критерій приймання: Відео без монтажу показує реальний запуск.

## Код-рев’ю

Попросіть колегу пройти quickstart з чистого середовища.

Критерій приймання: Quickstart працює без ваших підказок; зауваження виправлено.

## Що здати

Посилання на commit (або diff) і коротку нотатку з командою перевірки.
