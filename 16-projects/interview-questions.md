# Питання для співбесіди 16: Портфоліо-проєкти

Три питання з ключем відповіді: спершу відповідь вголос, потім звірка.

## Розкажіть про найскладніший проєкт

- STAR: ситуація, задача, дії, результат
- Числа: латентність, обсяг, час
- Що б зробили інакше

## Як ви перевіряєте чужі quickstart-и?

- Чисте середовище/контейнер
- README як єдине джерело істини
- Фіксація розбіжностей як issue/PR

## Що показати, якщо проєкт не завершено?

- Чесний розділ «обмеження» і план
- Робочий MVP із тестами
- Рішення, які вже працюють end-to-end

## Практика

Записуйте себе: ≤2 хвилини, структура — суть, механізм, приклад.
