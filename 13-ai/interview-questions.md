# Питання для співбесіди 13: AI у DefenseTech

Три питання з ключем відповіді: спершу відповідь вголос, потім звірка.

## Як ви застосовуєте LLM у системі з вимогами безпеки?

- Генерація + сувора валідація кодом
- Людина підтверджує критичні дії
- Fallback і локальні моделі для чутливих даних

## Як оцінюєте якість AI-функції?

- Golden set і метрики: schema pass rate, геозона, час
- Регресійні прогони в CI
- Ручна перевірка критичних кейсів

## Що таке RAG і коли він не потрібен?

- Пошук контексту + генерація з опорою на джерела
- Не потрібен, якщо знання стабільні й малі — краще правила
- Fine-tuning — для стилю/формату, не для фактів
