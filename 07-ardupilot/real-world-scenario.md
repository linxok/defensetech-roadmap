# Реальний сценарій 07: ArduPilot: керування польотом

## Контекст

Оператор натискає «Takeoff», інтерфейс показує успіх, але дрон не злітає. Через хвилину з’ясовується, що команда була відхилена автопілотом.

## Питання

1. Де саме загубився COMMAND_ACK і його result?
2. Чому UI не мав показувати успіх до підтвердження?
3. Які стани сесії треба показувати оператору?

## Обмеження

- Жодна команда не вважається виконаною без ACK
- UI показує останній підтверджений стан
- Таймаут команди — 5 секунд

## Результат

Схема рішення, список технологій з обґрунтуванням, план перевірки та
перелік ризиків — у нотатках або презентації.
