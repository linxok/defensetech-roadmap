# Розширений гайд 07: ArduPilot: керування польотом

Цикл навчання — у `docs/learning-workflow.md`. Нижче — маршрут модуля.

## Порядок проходження

1. Запустіть SITL (`sim_vehicle.py -v ArduCopter` — він сам відкриває TCP 5762).
2. Підключіться pymavlink і прочитайте поточний режим із HEARTBEAT.
3. ARM → takeoff → зміна висоти → RTL за допомогою прикладів.
4. Обгорніть кожну команду в очікування ACK із timeout.
5. Запустіть `checks/check_lab.py` — він підмінює SITL фейком.
6. Перевірте failsafe: підніміть, вимкніть RC, подивіться RTL.

## Орієнтовний час

2 тижні (12–16 годин)

## Артефакти модуля

- `ardupilot_api.py`
- лог польоту в SITL
- чекліст failsafe-перевірок

## Пастки цього модуля

- TCP 5762 vs UDP 14550 — різні шляхи, не плутайте
- GUIDED без GPS lock: takeoff відхиляється
- ACK приходить із result=4 (FAILED) — читайте поле
