# Реальний сценарій 03: Мережі для робототехніки

## Контекст

Дрон літає за 3 км, відео йде через LTE, телеметрія — через SiK-радіо. У GCS періодично зникає позиція на 2–3 секунди.

## Питання

1. Як відрізнити втрату на радіо від помилки в шлюзі?
2. Які поля логувати, щоб це діагностувати?
3. Як зробити UI стійким до пропусків?

## Обмеження

- Тільки один частотний канал
- Втрати до 5% вважаються нормою
- UI не має показувати «0,0» замість останньої позиції

## Результат

Схема рішення, список технологій з обґрунтуванням, план перевірки та
перелік ризиків — у нотатках або презентації.
