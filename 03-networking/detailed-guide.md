# Розширений гайд 03: Мережі для робототехніки

Цикл навчання — у `docs/learning-workflow.md`. Нижче — маршрут модуля.

## Порядок проходження

1. Реалізуйте UDP-сервер, який логує кожен пакет із адресою джерела.
2. Напишіть валідатор пакета: JSON-об’єкт із полем `drone_id` або `type`.
3. Підключіть WebSocket-клієнт і перегляньте потік у браузері.
4. Зніміть трафік через tcpdump і знайдіть у ньому свій пакет.
5. Помилкові пакети не мають ламати сервер — перевірте це навмисно.

## Орієнтовний час

1–2 тижні (6–10 годин)

## Артефакти модуля

- `udp_ws_bridge.py`
- pcap-файл із трафіком
- нотатка про вибір транспорту

## Пастки цього модуля

- UDP-сокет без `setblocking(False)` блокує event loop
- WebSocket-клієнти без видалення з набору течуть пам’яттю
