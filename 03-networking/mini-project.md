# Мініпроєкт 03: Мережі для робототехніки

## Мета

UDP/WebSocket-шлюз із метриками і стійкістю до сміттєвого трафіку.

## Вимоги

1. лічильники пакетів і помилок
2. HTTP `/metrics` у форматі Prometheus
3. конфігурація портів через env
4. тест на 1000 пакетів без втрат пам’яті

## Definition of Done

- `/metrics` доступний і коректний
- Битий пакет не зупиняє шлюз
- Пам’ять стабільна після 10 000 пакетів
- README з прикладом curl
