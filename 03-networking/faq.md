# FAQ 03: Мережі для робототехніки

Питання, які реально виникають під час цього модуля.

## Чому два процеси не можуть слухати один UDP-порт?

Можуть лише з `SO_REUSEPORT`, і пакети розподіляються ядром. Правильніше — один приймач і внутрішня розсилка.

## Як тестувати без дрона?

Генератором пакетів: `python -c` із циклом `socket.sendto` або прикладом `udp_client.py`.

## Який формат телеметрії обрати?

JSON — просто; CBOR/Protobuf — компактніше. Для курсу JSON, для ефіру — бінарні формати.
