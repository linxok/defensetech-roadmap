# Питання для співбесіди 09: ROS2: мости телеметрії

Три питання з ключем відповіді: спершу відповідь вголос, потім звірка.

## Як інтегрувати MAVLink-дрон із ROS2?

- Міст на companion: pymavlink читає MAVLink, публікує в ROS2
- Чиста логіка конвертації тестується окремо
- QoS best_effort для 50 Гц, reliable для команд

## Чому ROS2 використовує DDS, а не брокер?

- Peer-to-peer discovery без єдиної точки відмови
- QoS-контроль на рівні підписки
- Складніше в налагодженні мережі — потрібен досвід

## Як тестувати ROS2-вузли в CI?

- Виділити чисту логіку і тестувати її без rclpy
- launch_testing для інтеграційних тестів
- Для повного ROS2 — контейнер з образом ros:humble
