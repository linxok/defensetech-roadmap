- `python3 -m venv venv && source venv/bin/activate` — ізоляція залежностей
- `pip install -r requirements.txt -r requirements-dev.txt` — усе для курсу

- `COMPOSE_PROFILES=sitl docker compose up` — режим справжнього SITL
- `git switch -c week-01` — окрема гілка на тиждень
