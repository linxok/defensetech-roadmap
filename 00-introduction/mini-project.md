# Мініпроєкт 00: Вступ

## Мета

Публічний репозиторій-трекер навчання, який оновлюється щотижня.

## Вимоги

1. README з обраним треком і мілстоунами
2. папка `notes/` з конспектами модулів
3. папка `labs/` з рішеннями лабораторних
4. CI, який запускає `python -c "print('ok')"` на кожен push

## Definition of Done

- Репозиторій публічний
- README містить актуальний прогрес
- ≥2 commit-и різних днів
- CI-бейдж зелений

## Орієнтовний обсяг

3–4 години

## Публікація

Зробіть окремий публічний репозиторій і додайте його у CV.
