# Приклади 00: Вступ

Прикладів коду в цьому модулі немає: він про процес. Еталон плану — `solution/plan-example.md`.

Заповніть свій `plan.md` за цим зразком (розділи: ціль, трек, бюджет,
мілстоуни, метрики) і перевірте його:

```bash
python 00-introduction/checks/check_lab.py --target <тека з plan.md>
```

Скрипт шукає `plan.md`, `learning-plan.md` або `plan-example.md` і перевіряє
наявність розділів, таблицю мілстоунів та бюджет годин у числах.
