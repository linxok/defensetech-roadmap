# Лабораторна робота 00: план навчання

## Мета

Зафіксувати трек, тижневий бюджет і мілстоуни так, щоб їх можна було
перевірити датами та артефактами.

## Передумови

- Python 3.11+, Docker (для capstone).
- Репозиторій курсу клоновано, venv налаштовано.

## Кроки

1. Скопіюйте `solution/plan-example.md` у свій репозиторій як `plan.md`.
2. Заповніть розділи: ціль, трек, тижневий бюджет, мілстоуни, метрики.
3. Для кожного мілстоуна вкажіть дату та бінарний критерій.
4. Перевірте середовище командами:

```bash
python -c "import fastapi, pymavlink; print('deps ok')"
docker run --rm hello-world
```

5. Запустіть перевірку плану (еталон, потім ваша тека з `plan.md`):

```bash
python 00-introduction/checks/check_lab.py --target 00-introduction/solution
python 00-introduction/checks/check_lab.py --target <тека з вашим plan.md>
```

## Очікуваний результат

- `plan.md` із 8+ мілстоунами, датами й числами годин.
- Робоче середовище: залежності встановлені, Docker відповідає.
- Перший commit у власному репозиторії-трекері.

## Перевірка

`checks/check_lab.py` перевіряє наявність розділів, таблицю мілстоунів
і бюджет годин у числах. На порожній теці скрипт падає — це критерій
готовності.

## Розбір збоїв

- `docker: permission denied` — користувач не в групі `docker`;
  перелогіньтеся після `sudo usermod -aG docker $USER`.
- `ModuleNotFoundError: fastapi` — venv не активовано.
- План без дат проходить перевірку, але не виконує мети: дати — це
  механізм, який змушує завершувати модулі.
