# FAQ 00: Вступ

Питання, які реально виникають під час цього модуля.

## Чи можна проходити модулі не по порядку?

Можна, але 06–09 спираються на 02–05. Оглядові модулі (10–17) можна читати пізніше за потреби.

## Що робити, якщо Docker не запускається?

Спершу `docker run hello-world`; на Linux перевірте групу `docker` і права сокета. Без Docker capstone можна підняти локально — див. README.

## Чи обов’язковий GitHub?

Публічність — це механізм зворотного зв’язку і доказ навичок. Якщо публічність неможлива, ведіть локальний git з тим самим режимом комітів.
