# Питання для співбесіди 14: Наземна станція (GCS)

Три питання з ключем відповіді: спершу відповідь вголос, потім звірка.

## Як UI має показувати втрату зв’язку?

- Стан з’єднання окремим індикатором
- Застарілі дані приглушуються/помічаються
- Жодних «нулів» замість невідомого

## Як оптимізувати мапу з тисячами точок?

- Ring buffer і decimation
- Canvas-шар або WebGL замість DOM-маркерів
- Завантаження історії окремо від live-потоку

## Як тестувати фронтенд у CI?

- Чисті функції через node --test
- Компонентні тести (React Testing Library) за потреби
- E2E — лише для критичних шляхів
