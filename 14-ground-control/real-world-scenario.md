# Реальний сценарій 14: Наземна станція (GCS)

## Контекст

Оператор втратив зв’язок на 20 секунд, а UI продовжував показувати останню позицію як актуальну.

## Питання

1. Як UI має позначати застарілі дані?
2. Через який час показувати «no link»?
3. Що показувати замість останньої позиції?

## Обмеження

- «No link» протягом 3 с
- Без блокування UI
- Історія останніх 5 хвилин доступна

## Результат

Схема рішення, список технологій з обґрунтуванням, план перевірки та
перелік ризиків — у нотатках або презентації.
