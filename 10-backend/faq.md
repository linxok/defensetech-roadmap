# FAQ 10: Backend для телеметрії

Питання, які реально виникають під час цього модуля.

## Чому не Kafka?

Для курсу RabbitMQ простіший; Kafka — у модулі 11. Критерії: порядок, партиції, retention.

## Чи можна замість RabbitMQ використати Redis Streams?

Так, для легшого стеку. Але ack-семантика і DLQ у RabbitMQ наочніші для навчання.

## Де зберігати останній стан для UI?

Redis: `SET telemetry:{drone_id}` з TTL. Це швидше за запит до БД.
