# Питання для співбесіди 11: Розподілені системи

Три питання з ключем відповіді: спершу відповідь вголос, потім звірка.

## REST чи gRPC для флоту дронів?

- gRPC для внутрішнього зв’язку: стрімінг, кодогенерація, HTTP/2
- REST — для інтеграцій і браузера
- Рішення залежить від затримки і типів клієнтів

## Як побудувати топік-схему телеметрії у Kafka?

- Partitions за hash(drone_id) для порядку
- Retention за вимогами, tiered storage за потреби
- Consumer groups для паралельних обробників

## Що таке часткова відмова і як до неї готуватися?

- Частина вузлів недоступна, система має деградувати
- Retry з backoff, ідемпотентність, circuit breaker
- Спостережуваність на кожній межі
