# Course FAQ

Питання про курс загалом. Технічні питання конкретних модулів — у
`faq.md` відповідного модуля.

## Який трек обрати?

Один. Рекомендований для цього репозиторію — **Drone / Autopilot
Software** (модулі 05–09 поглиблено, решта оглядово). Альтернативи:
Onboard CV/AI (12–13), Backend/Platform GCS (10–11, 14–15).
Розпорошення на кілька треків одразу — головна причина, чому курси не
закінчують.

## Чи потрібен реальний дрон?

Ні на старті. SITL (software-in-the-loop) покриває більшість завдань:
`sim_vehicle.py -v ArduCopter` дає повноцінний MAVLink-потік без
заліза. Реальний kit (~$85–170) має сенс після 2–3 тижнів успішного
SITL — деталі в `notes/beginner-drone-kits.md`.

## Що найважливіше: Python чи C++?

Для треку Drone/Autopilot: Python — швидкий прототип, інтеграції,
GLUE-код (pymavlink, MAVSDK, FastAPI). C++ — прошивки, парсери,
продуктивні частини (ArduPilot, PX4). Senior-рівень передбачає
впевненість в обох, але глибина може бути різна.

## Скільки часу реально потрібно?

6–9 місяців part-time (~12–15 год/тиждень, 500–700 год) до рівня
впевненого співбесіду. Розклад із результатами — у
`STUDY_SCHEDULE.md`. Розклад 38×30 год був нереалістичний і замінений.

## Як зрозуміти, що модуль засвоєно?

Модуль засвоєно, якщо: `checks/` проходить на вашому рішенні,
контрольні питання з README мають відповіді з посиланням на код, і
ви можете повторити лабораторну з нуля за 30 хвилин без підказок.
Статуси модулів (`stub`/`outline`/`complete`) описані в
`CONTENT_STANDARD.md`.

## Як публікувати прогрес?

Один публічний артефакт на тиждень: commit у власному репозиторії,
README компонента, короткий пост. Для найму працює не кількість
репозиторіїв, а один end-to-end проєкт з тестами й демо — див.
`capstone/`.

## Де шукати вакансії?

LinkedIn, Djinni, українські DefenseTech компанії та міжнародні
robotics/drone компанії. Перед співбесідою — `17-interview/`.
Перед відгуком перевірте, що профіль демонструє саме той трек,
який ви обрали.
