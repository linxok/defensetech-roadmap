# Апаратні рекомендації

Детальний поетапний план із цінами — у
[`notes/beginner-drone-kits.md`](../notes/beginner-drone-kits.md).
Тут — стисла мапа рішень.

## Поетапний шлях

| Етап | Залізо | Бюджет | Коли переходити |
|---|---|---|---|
| 0 | тільки SITL | $0 | старт; поки всі лабораторні не проходять |
| 1 | контролер + рама + мотори (kit) | $85–170 | після 2–3 тижнів стабільного SITL |
| 2 | companion computer (RPi/Jetson) | $60–250 | коли потрібні MAVLink-шлюзи й CV |
| 3 | телеметрія дальньої дії, камера | $100+ | коли є реальні польотні сценарії |

## Flight controllers

- **Pixhawk 6C** — сучасний бюджетний стандарт для ArduPilot/PX4.
- **Pixhawk 2.4.8** — дешевий, але застарілий: для навчання придатний,
  для проєктів — ризикований.
- **Cube Orange** — професійний, для серйозних платформ.

## Companion computer

- **Raspberry Pi 4/5** — MAVLink-шлюзи, ROS2, легкий CV.
- **NVIDIA Jetson Orin Nano** — CV/AI на edge, TensorRT.
- **Orange Pi / Radxa** — бюджетні альтернативи з обмеженою підтримкою.

## Телеметрія та відео

- **SiK Radio 433/915 МГц** — базова телеметрія на сотні метрів.
- **RFD900x** — кілометри, вища ціна.
- **Herelink** — керування + HD-відео в одному лінку.

## Камери

- **RPi Camera Module** — CSI, добре для Jetson/RPi CV.
- **USB UVC** — універсальна, працює скрізь.
- **FLIR/тепловізор** — нічні сценарії, окремий бюджет.

## Правила безпеки

- Пропелери знімаються до першого ARM на реальному залізі.
- Польоти — лише на майданчику, дозволеному локальними правилами.
- Перед кожним польотом: failsafe, геозона, RTL-перевірка в SITL.
