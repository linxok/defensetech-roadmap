# FAQ 06: MAVLink: протокол і gateway

Питання, які реально виникають під час цього модуля.

## Чому gateway не бачить heartbeat, хоча SITL працює?

Перевірте напрямок і порт: `--out=udp:127.0.0.1:14550` від SITL, а gateway має слухати той самий порт. QGC не має бути підключений тим самим сокетом.

## Чи можна використовувати MAVSDK замість pymavlink?

Так, MAVSDK зручніший для команд і телеметрії вищого рівня. pymavlink дає повний контроль над кадрами — кращий для навчання.

## Як зберігати історію кадрів для тестів?

Пишіть сирі байти у файл (`recv` без парсингу) і додайте replay-режим. Це дає офлайн-тести без SITL.
