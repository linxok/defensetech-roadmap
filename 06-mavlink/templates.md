# Шаблони 06: MAVLink: протокол і gateway

Спільні шаблони лежать у `docs/templates.md`, щоб не дублюватися між
модулями. Для цього модуля актуальні:

- MAVLink-повідомлення з фікстури — для офлайн-тестів кадрів
- Async worker — патерн циклу читання
- Тест, який падає на поганому вході — для битих кадрів
