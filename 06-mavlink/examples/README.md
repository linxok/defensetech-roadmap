# Приклади 06: MAVLink: протокол і gateway

У `examples/` — heartbeat, парсер батареї, спрощений gateway (один клієнт, без lock і дедуплікації) і браузерний клієнт `websocket_client.html`. Фікстури кадрів генеруються в тестах через pymavlink.

Запуск: `pip install -r requirements.txt` (venv репозиторію).
