# Практика 06: MAVLink: протокол і gateway

## Завдання

Перепишіть gateway так, щоб він писав у дві цілі одночасно: WebSocket і HTTP-backend, і падіння однієї не зупиняло іншу.

Без підказок: у `solution/` не підглядати, доки не буде робочого
результату. Якщо застрягли — поверніться до `lab.md`.

## Типові збої

- Обидві цілі в одному try — збій HTTP вбиває WebSocket
- Немає таймауту на HTTP — черга кадрів росте
- Відсутня метрика відкинутих кадрів

## Перевірка

Вимкніть backend — WebSocket має продовжити віддавати дані, а метрика помилок — рости.
