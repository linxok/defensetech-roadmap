# Мініпроєкт 02: Linux для робототехніки

## Мета

Утиліта `drone-serial` для моніторингу serial-портів із метриками.

## Вимоги

1. systemd unit і udev-правило
2. метрики: байти/с, помилки кадру, час останнього пакета
3. логування у journald з рівнями
4. README з інструкцією встановлення

## Definition of Done

- Сервіс стартує після reboot
- `systemctl status drone-serial` показує активний стан
- Збій порту не валить процес
- Метрики видно в journalctl
