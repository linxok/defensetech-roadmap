# Самоперевірка 02: Linux для робототехніки

## Питання

1. Що робить `Restart=on-failure` при коді виходу 0?
2. Який порядок перевірки udev-правила?
3. Чим відрізняється `WantedBy` від `RequiredBy`?
4. Як обмежити сервіс 256 МБ пам’яті?
5. Як переглянути логи лише за останню годину?

## Завдання без підказок

- Створити unit-файл з нуля за 10 хвилин
- Відтворити перезапуск сервісу при збої
- Знайти свій USB-пристрій через `udevadm info`
- Пояснити різницю journald і syslog
- Налаштувати `MemoryMax` і перевірити ефект
