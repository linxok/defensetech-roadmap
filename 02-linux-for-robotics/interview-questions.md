# Питання для співбесіди 02: Linux для робототехніки

Три питання з ключем відповіді: спершу відповідь вголос, потім звірка.

## Як ви забезпечите автозапуск польотного сервісу після живлення?

- systemd unit + `WantedBy=multi-user.target`
- `After=network-online.target` для мережевих залежностей
- Restart-політика і resource limits

## Користувач скаржиться, що serial-порт зникає. Ваші дії?

- `dmesg` і `journalctl -k` — чи бачить ядро пристрій
- `udevadm monitor` — події підключення
- Стабільний symlink за vendor/product ID замість номера порту

## Коли варто використовувати CAN замість UART?

- Кілька пристроїв на одній шині з арбітражем
- Стійкість до завад у довгих кабелях
- Детерміновані пріоритети кадрів для критичних команд
