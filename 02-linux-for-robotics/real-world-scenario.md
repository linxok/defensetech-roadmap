# Реальний сценарій 02: Linux для робототехніки

## Контекст

Після оновлення ядра на companion-комп’ютері serial-порт перестав з’являтися як `/dev/ttyUSB0`, а сервіс почав циклічно перезапускатися.

## Питання

1. Як знайти, під яким іменем тепер пристрій?
2. Чому сервіс перезапускається, а не падає остаточно?
3. Як зробити правило, стійке до зміни USB-портів?

## Обмеження

- Без root для самого сервісу
- Журнал обмежений 10 МБ
- Відновлення після reboot без ручних дій

## Результат

Схема рішення, список технологій з обґрунтуванням, план перевірки та
перелік ризиків — у нотатках або презентації.
