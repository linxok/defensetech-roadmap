# FAQ 15: DevOps для флоту

Питання, які реально виникають під час цього модуля.

## Compose чи K8s для навчання?

Compose для локальної розробки, K8s — щоб показати розуміння експлуатації. Для портфоліо досить обох.

## Чи потрібен Helm?

Для одного сервісу — ні. Helm виправданий, коли сервісів багато й потрібні релізи/шаблони.

## Як тестувати деплой без кластера?

kind/minikube локально або kubeconform для валідації манифестів у CI.
