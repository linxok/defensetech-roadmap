# Питання для співбесіди 15: DevOps для флоту

Три питання з ключем відповіді: спершу відповідь вголос, потім звірка.

## Як ви організуєте CI/CD для сервісу?

- Етапи: lint → тести → збірка → smoke → деплой
- Кеш залежностей і матриця версій
- Артефакти з тегами й можливість відкату

## Як зробити контейнер безпечним?

- Pinned base, non-root, мінімум пакетів
- Сканування уразливостей
- Read-only FS і ліміти ресурсів за потреби

## Які метрики і алерти для телеметрії?

- Черга: lag, розмір, DLQ
- API: error rate, p95 latency
- Хост: CPU/RAM/диск

## Практика

Записуйте себе: ≤2 хвилини, структура — суть, механізм, приклад.
