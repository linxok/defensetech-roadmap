# Практика 15: DevOps для флоту

## Завдання

Зламайте стек: зупиніть БД, перевірте, що API не падає остаточно, а probes не перезапускають його в циклі.

Без підказок: у `solution/` не підглядати, доки не буде робочого
результату. Якщо застрягли — поверніться до `lab.md`.

## Типові збої

- Readiness не враховує стан БД
- Liveness вбиває сервіс під час довгого старту
- Немає логів про причину недоступності

## Перевірка

Звіт: поведінка API, стан probes, час відновлення після старту БД.
