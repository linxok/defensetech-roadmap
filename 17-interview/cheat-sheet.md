# Cheat Sheet 17: Підготовка до співбесіди

- Таймінг: 90–120 с на технічну відповідь, пауза до 5 с перед нею; system design — 25–35 хв діалогу.
- Структура технічної відповіді: суть (1 речення) → механізм (2–3) → приклад з capstone (1–2) → обмеження (1).
- STAR: Situation → Task → Action → Result; у Result — конкретне число (p95, час, обсяг, кількість).
- Банк тем (12 питань): MAVLink 2 і `crc_extra`, signing, `COMMAND_ACK`, failsafe RC, asyncio + pymavlink, RAII/thread pool, known-answer тести парсера, durable-черга, часткова відмова, gRPC/REST/MQTT, YOLO на Jetson, телеметрія 1000 дронів — повний перелік у `interview-questions.md`.
- System design: вимоги → оцінки (msg/s, ГБ/добу) → схема → вузькі місця → відмови; завершіть фразою «що зламається першим і чому».
- П’ять STAR-історій закривають: конфлікт, дедлайн, власну помилку, ініціативу, складний технічний вибір.
- Питання інтерв’юеру: 3 заготовки — процес розробки, тестування на залізі, code review.
- «Не знаю» + план, як дізнатися, сильніше за вигадку; назвіть суміжний досвід.
- Мок-співбесіда: 2 сесії по 30 хв із записом, розбір за 15 хв; зони росту фіксуйте письмово.
