# Розширений гайд 04: Python для телеметрії

Цикл навчання — у `docs/learning-workflow.md`. Нижче — маршрут модуля.

## Порядок проходження

1. Запустіть `uvicorn fastapi_telemetry:app --reload` з теки `examples/` і перевірте `/docs`.
2. Відправте валідний POST і подивіться код відповіді 201.
3. Відправте battery=150 і подивіться на структуру 422.
4. Запустіть `python checks/check_lab.py --target solution`.
5. Порівняйте свій код із `solution/main.py` — лише після спроби.

## Орієнтовний час

1–2 тижні (8–12 годин)

## Артефакти модуля

- `main.py` з моделями і сховищем
- тестовий прогін checks
- README з прикладами curl

## Пастки цього модуля

- uvicorn без `--reload` не бачить правок
- `python3 -m venv` без активації встановить пакети глобально
