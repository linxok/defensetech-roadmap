# Практика 04: Python для телеметрії

## Завдання

Додайте WebSocket `/ws/telemetry`, який віддає кожне нове вимірювання всім підключеним клієнтам.

Без підказок: у `solution/` не підглядати, доки не буде робочого
результату. Якщо застрягли — поверніться до `lab.md`.

## Типові збої

- Клієнт без видалення після disconnect — ріст пам’яті
- Розсилка через `asyncio.wait` — помилка на Python 3.12
- Повільний клієнт блокує інших у циклі

## Перевірка

Підключіть два WebSocket-клієнти; обидва мають отримувати події, а disconnect одного не ламає інший.
