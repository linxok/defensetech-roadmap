# FAQ 04: Python для телеметрії

Питання, які реально виникають під час цього модуля.

## Чому 422, а не 400?

422 — це семантична помилка валідації, яку FastAPI/Pydantic повертає автоматично. 400 лишається для явних помилок клієнта.

## Чи потрібна база даних у цьому модулі?

Ні, достатньо сховища в пам’яті. База з’явиться в capstone, інтерфейс `TelemetryStore` уже це передбачає.

## Як запустити тести без SITL?

SITL не потрібен: створюйте дані напряму через TestClient. Саме тому API тестується швидко.
