# Реальний сценарій 04: Python для телеметрії

## Контекст

Оператор відкриває GCS, і сервіс телеметрії починає відповідати із затримкою 5 секунд, хоча дронів лише три.

## Питання

1. Які блокуючі виклики можуть спричинити це?
2. Як підтвердити гіпотезу виміром, а не здогадом?
3. Як зробити сервіс стійким до повільного споживача?

## Обмеження

- Менше 100 мс на відповідь API
- Жодних нових бібліотек без обґрунтування
- Дані не можна втрачати при перезапуску

## Результат

Схема рішення, список технологій з обґрунтуванням, план перевірки та
перелік ризиків — у нотатках або презентації.
