# Питання для співбесіди 04: Python для телеметрії

Три питання з ключем відповіді: спершу відповідь вголос, потім звірка.

## Як ви поєднуєте синхронний pymavlink з asyncio?

- `asyncio.to_thread` для `recv_match` і `wait_heartbeat`
- Один потік на з’єднання; таймаути обов’язкові
- Закриття з’єднання у `finally` або lifespan

## Як валідуєте вхідні дані телеметрії?

- Pydantic-модель із фізичними межами
- 422 з переліком проблемних полів
- Відхилені пакети логуються з причиною, без зупинки сервісу

## Що зробите перед викаткою зміни API?

- Контрактні тести на 2xx/4xx (422 на невалідні поля); WebSocket-розширення з `practice.md` — перевірка двома клієнтами
- Перевірка зворотної сумісності полів
- Метрика помилок і план відкату
