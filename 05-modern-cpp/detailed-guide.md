# Розширений гайд 05: Сучасний C++

Цикл навчання — у `docs/learning-workflow.md`. Нижче — маршрут модуля.

## Порядок проходження

1. Зберіть `thread_pool.cpp` і переконайтеся, що `sum_of_squares=204`.
2. Порівняйте зі старим прикладом: у чому різниця поведінки?
3. Реалізуйте `parser.hpp/cpp` за специфікацією серіалізації.
4. Звірте CRC із фреймом, згенерованим pymavlink (known-answer).
5. Запустіть `python checks/check_lab.py --target solution`.

## Орієнтовний час

2 тижні (12–16 годин)

## Артефакти модуля

- `thread_pool.cpp`
- `parser.cpp/hpp`
- `parser_test.cpp`

## Пастки цього модуля

- Заголовок без include guard спричиняє подвійне визначення
- CRC по magic-байту ламає сумісність із реальними фреймами
- `-pthread` обов’язковий і при лінкуванні
