# FAQ 05: Сучасний C++

Питання, які реально виникають під час цього модуля.

## Чому не використати готову C++ бібліотеку MAVLink?

Використовуйте в продакшені. Для навчання мета — зрозуміти формат: написавши парсер, ви читаєте чужі баги в парсерах.

## Який стандарт C++ обрати?

C++20: `std::span`, `std::jthread`, concepts. Доступний у GCC 12+ і Clang 16+, чого достатньо для Ubuntu 24.04.

## Що робити з `-Werror` у чужому коді?

Не ламати збірку сліпо: спершу подивіться попередження, потім або виправте, або локалізуйте придушення одним прагма-блоком.
