# Питання для співбесіди 05: Сучасний C++

Три питання з ключем відповіді: спершу відповідь вголос, потім звірка.

## Поясніть RAII на прикладі блокування м’ютекса

- `std::lock_guard` захоплює в конструкторі, звільняє в деструкторі
- Працює і при винятках — на відміну від ручного lock/unlock
- `std::scoped_lock` для кількох м’ютексів без deadlock

## Як реалізувати thread pool з нуля?

- Черга `std::function<void()>` під м’ютексом
- `condition_variable` для пробудження воркерів
- `packaged_task` для результату, `stopping_` для завершення

## Як перевірите парсер бінарного протоколу?

- Known-answer тести з фреймами еталонної реалізації
- Пошкодження байтів: CRC, довжина, magic
- Fuzzing випадковим потоком і контроль пам’яті sanitizer-ами
