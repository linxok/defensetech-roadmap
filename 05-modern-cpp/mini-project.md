# Мініпроєкт 05: Сучасний C++

## Мета

Бібліотека `mavlink-parser` з CLI: читає байти, друкує JSON-кадри.

## Вимоги

1. CMake-ціль з тестами (`ctest`)
2. потоковий парсер із буфером залишку
3. CLI `--file` і `--stdin`
4. fuzz-стійкість: 100 000 випадкових байт без падінь

## Definition of Done

- `ctest` зелений
- `-Wall -Wextra -Werror` без попереджень
- CLI обробляє битий потік і завершується коректно
- README з прикладом виводу
